# 📊 Madhav Ecommerce Sales Dashboard

An interactive **Ecommerce Sales Dashboard built with Microsoft Power BI** to analyze sales, quantity, profit, customers, categories, payment methods, sub-categories, states, and monthly performance.

The dashboard is designed to provide a clear business overview through interactive KPIs, charts, and quarterly filters.

---

## 🎯 Project Objective

The objective of this project is to build an interactive Power BI dashboard that helps understand ecommerce business performance from different dimensions.

The dashboard provides analysis of:

- Sales Amount
- Quantity
- Profit
- Average Order Value (AOV)
- State-wise sales
- Category-wise quantity
- Monthly profit
- Customer-wise sales
- Payment-mode analysis
- Sub-category profit
- Quarterly performance

## ▶️ How to Use the Project

1. Download `sales_project.pbix`.
2. Install **Microsoft Power BI Desktop**.
3. Open the `.pbix` file.
4. Review the report and interact with the available filters.
5. If the source data is unavailable on another system, some refresh operations may require reconnecting the original data source.
